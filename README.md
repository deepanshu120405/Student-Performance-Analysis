# Student Performance Analysis

## Objective
Analyze student performance using Python and Data Analysis techniques.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Subject-wise Performance Analysis
- Gender-wise Comparison
- Test Preparation Analysis
- Lunch Type Analysis
- Parent Education Analysis
- Correlation Heatmap

## Key Insights
- Students who completed test preparation courses performed better.
- Reading and writing scores are strongly correlated.
- Parent education level impacts student performance.

## Dataset
Students Performance in Exams Dataset from Kaggle.
